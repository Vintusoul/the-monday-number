# The Monday Number

A short, narrated case study on why product engineers still matter when AI writes the code.

**Watch it: https://vintusoul.github.io/the-monday-number/**

It plays like a guided video: a cover, ten scenes and a closing card, each with one illustration, a line of narration and sounds tied to the animation. The case is illustrative. The statistics are real and linked on the closing card.

Built with [Motion](https://motion.dev). Sound effects are synthesised in the browser with the Web Audio API. Narration generated with ElevenLabs.

This repo holds only the published page. The source lives in a private repo.
